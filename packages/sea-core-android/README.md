# sea-core-android

The Android SDK for SEA: a secure, native-feeling OAuth/OIDC login screen built
on a hardened `WebView`.

```kotlin
implementation("com.bankerise:sea-core-android:0.0.1")
```

See the [Android guide](../../docs/android.md) for setup and usage. The Gradle
build for this module lives in [`apps/demo-android`](../../apps/demo-android).
