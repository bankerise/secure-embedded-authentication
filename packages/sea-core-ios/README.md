# SEACore (iOS)

The iOS SDK for SEA: a secure, native-feeling OAuth/OIDC login screen built on
a hardened `WKWebView`.

```ruby
source 'https://cdn.cocoapods.org/'
source 'https://github.com/bankerise/secure-embedded-authentication.git'

pod 'SEACore', '~> 0.0.1'
```

See the [iOS guide](../../docs/ios.md) for setup and usage.
